# Contracts Directory

This directory contains formal schema definitions for the workshop content structure.

## Files

- **workshop-module.schema.json**: WorkshopModule entity schema
- **lab.schema.json**: Lab entity schema  
- **code-example.schema.json**: CodeExample entity schema
- **documentation-resource.schema.json**: DocumentationResource entity schema
- **technical-prerequisite.schema.json**: TechnicalPrerequisite entity schema
- **workshop-content-format.md**: Content formatting standards and conventions

## Purpose

These contracts define:

1. **Data structure** for workshop module metadata
2. **Content format** for markdown documentation
3. **Lab structure** for hands-on exercises
4. **Code standards** for C# examples

## Usage

These schemas can be used to:

- Validate workshop content structure programmatically
- Generate scaffolding for new modules/labs
- Ensure consistency across all workshop materials
- Guide content authors on required fields
